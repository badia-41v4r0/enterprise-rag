# AX-1067 Field controller

Product sheet for the AX-1067, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 385 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 156 EUR |

The AX-1067 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
