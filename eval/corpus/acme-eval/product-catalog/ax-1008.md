# AX-1008 Smart relay

Product sheet for the AX-1008, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 180 g |
| Power consumption | 5.0 W |
| Ingress protection | IP67 |
| Operating temperature | -10 °C to 50 °C |
| List price | 77 EUR |

The AX-1008 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
