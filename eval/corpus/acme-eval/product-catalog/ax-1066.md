# AX-1066 Edge gateway

Product sheet for the AX-1066, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 765 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -30 °C to 70 °C |
| List price | 283 EUR |

The AX-1066 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
