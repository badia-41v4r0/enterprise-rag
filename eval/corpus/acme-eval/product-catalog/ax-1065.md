# AX-1065 Temperature and humidity sensor

Product sheet for the AX-1065, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 450 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -30 °C to 70 °C |
| List price | 530 EUR |

The AX-1065 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
