# AX-1040 Smart relay

Product sheet for the AX-1040, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 270 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -10 °C to 50 °C |
| List price | 95 EUR |

The AX-1040 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
