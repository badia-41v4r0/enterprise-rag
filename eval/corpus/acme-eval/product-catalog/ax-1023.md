# AX-1023 Field controller

Product sheet for the AX-1023, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 385 g |
| Power consumption | 3.5 W |
| Ingress protection | IP65 |
| Operating temperature | -20 °C to 60 °C |
| List price | 521 EUR |

The AX-1023 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
