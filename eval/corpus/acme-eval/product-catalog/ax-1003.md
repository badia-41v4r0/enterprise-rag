# AX-1003 Field controller

Product sheet for the AX-1003, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 610 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -40 °C to 85 °C |
| List price | 183 EUR |

The AX-1003 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
