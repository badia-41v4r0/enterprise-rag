# AX-1029 Temperature and humidity sensor

Product sheet for the AX-1029, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 875 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -40 °C to 85 °C |
| List price | 409 EUR |

The AX-1029 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
