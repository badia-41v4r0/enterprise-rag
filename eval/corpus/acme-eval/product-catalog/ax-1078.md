# AX-1078 Edge gateway

Product sheet for the AX-1078, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 85 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -40 °C to 85 °C |
| List price | 479 EUR |

The AX-1078 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
