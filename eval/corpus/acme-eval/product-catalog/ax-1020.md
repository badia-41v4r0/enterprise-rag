# AX-1020 Smart relay

Product sheet for the AX-1020, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 555 g |
| Power consumption | 1.5 W |
| Ingress protection | IP65 |
| Operating temperature | -20 °C to 60 °C |
| List price | 163 EUR |

The AX-1020 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
