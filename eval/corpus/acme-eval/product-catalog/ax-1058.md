# AX-1058 Edge gateway

Product sheet for the AX-1058, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 600 g |
| Power consumption | 3.5 W |
| Ingress protection | IP65 |
| Operating temperature | -40 °C to 85 °C |
| List price | 460 EUR |

The AX-1058 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
