# AX-1042 Edge gateway

Product sheet for the AX-1042, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 175 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -20 °C to 60 °C |
| List price | 60 EUR |

The AX-1042 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
