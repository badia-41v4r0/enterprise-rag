# AX-1055 Field controller

Product sheet for the AX-1055, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 740 g |
| Power consumption | 2.0 W |
| Ingress protection | IP54 |
| Operating temperature | -30 °C to 70 °C |
| List price | 475 EUR |

The AX-1055 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
