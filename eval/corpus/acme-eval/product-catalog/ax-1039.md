# AX-1039 Field controller

Product sheet for the AX-1039, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 565 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -30 °C to 70 °C |
| List price | 461 EUR |

The AX-1039 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
