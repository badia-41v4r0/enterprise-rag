# AX-1043 Field controller

Product sheet for the AX-1043, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 380 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -30 °C to 70 °C |
| List price | 286 EUR |

The AX-1043 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
