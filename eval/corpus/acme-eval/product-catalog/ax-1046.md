# AX-1046 Edge gateway

Product sheet for the AX-1046, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 130 g |
| Power consumption | 7.5 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 255 EUR |

The AX-1046 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
