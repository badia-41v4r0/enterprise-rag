# AX-1052 Smart relay

Product sheet for the AX-1052, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 825 g |
| Power consumption | 3.5 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 509 EUR |

The AX-1052 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
