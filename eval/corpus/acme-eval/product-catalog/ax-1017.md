# AX-1017 Temperature and humidity sensor

Product sheet for the AX-1017, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 115 g |
| Power consumption | 5.0 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 135 EUR |

The AX-1017 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
