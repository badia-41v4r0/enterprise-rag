# AX-1063 Field controller

Product sheet for the AX-1063, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 295 g |
| Power consumption | 5.0 W |
| Ingress protection | IP67 |
| Operating temperature | -40 °C to 85 °C |
| List price | 440 EUR |

The AX-1063 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
