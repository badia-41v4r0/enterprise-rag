# AX-1035 Field controller

Product sheet for the AX-1035, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 820 g |
| Power consumption | 3.5 W |
| Ingress protection | IP67 |
| Operating temperature | -20 °C to 60 °C |
| List price | 373 EUR |

The AX-1035 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
