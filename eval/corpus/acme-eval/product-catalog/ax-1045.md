# AX-1045 Temperature and humidity sensor

Product sheet for the AX-1045, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 700 g |
| Power consumption | 7.5 W |
| Ingress protection | IP65 |
| Operating temperature | -30 °C to 70 °C |
| List price | 97 EUR |

The AX-1045 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
