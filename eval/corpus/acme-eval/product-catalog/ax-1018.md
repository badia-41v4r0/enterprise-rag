# AX-1018 Edge gateway

Product sheet for the AX-1018, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 390 g |
| Power consumption | 3.5 W |
| Ingress protection | IP65 |
| Operating temperature | -30 °C to 70 °C |
| List price | 320 EUR |

The AX-1018 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
