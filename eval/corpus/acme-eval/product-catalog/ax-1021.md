# AX-1021 Temperature and humidity sensor

Product sheet for the AX-1021, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 420 g |
| Power consumption | 3.5 W |
| Ingress protection | IP67 |
| Operating temperature | -40 °C to 85 °C |
| List price | 197 EUR |

The AX-1021 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
