# AX-1027 Field controller

Product sheet for the AX-1027, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 140 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -20 °C to 60 °C |
| List price | 636 EUR |

The AX-1027 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
