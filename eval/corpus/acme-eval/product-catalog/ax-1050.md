# AX-1050 Edge gateway

Product sheet for the AX-1050, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 885 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -30 °C to 70 °C |
| List price | 649 EUR |

The AX-1050 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
