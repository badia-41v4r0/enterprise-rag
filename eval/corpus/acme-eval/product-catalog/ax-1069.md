# AX-1069 Temperature and humidity sensor

Product sheet for the AX-1069, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 890 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -10 °C to 50 °C |
| List price | 96 EUR |

The AX-1069 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
