# AX-1001 Temperature and humidity sensor

Product sheet for the AX-1001, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 710 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -40 °C to 85 °C |
| List price | 256 EUR |

The AX-1001 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
