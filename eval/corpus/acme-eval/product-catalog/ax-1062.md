# AX-1062 Edge gateway

Product sheet for the AX-1062, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 830 g |
| Power consumption | 5.0 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 114 EUR |

The AX-1062 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
