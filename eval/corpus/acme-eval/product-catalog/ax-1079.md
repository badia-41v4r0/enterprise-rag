# AX-1079 Field controller

Product sheet for the AX-1079, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 530 g |
| Power consumption | 3.5 W |
| Ingress protection | IP65 |
| Operating temperature | -40 °C to 85 °C |
| List price | 669 EUR |

The AX-1079 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
