# AX-1032 Smart relay

Product sheet for the AX-1032, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 415 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -30 °C to 70 °C |
| List price | 396 EUR |

The AX-1032 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
