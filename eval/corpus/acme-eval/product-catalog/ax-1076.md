# AX-1076 Smart relay

Product sheet for the AX-1076, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 365 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -40 °C to 85 °C |
| List price | 551 EUR |

The AX-1076 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
