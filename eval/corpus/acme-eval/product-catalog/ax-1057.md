# AX-1057 Temperature and humidity sensor

Product sheet for the AX-1057, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 460 g |
| Power consumption | 5.0 W |
| Ingress protection | IP67 |
| Operating temperature | -30 °C to 70 °C |
| List price | 123 EUR |

The AX-1057 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
