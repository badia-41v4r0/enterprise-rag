# AX-1054 Edge gateway

Product sheet for the AX-1054, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 395 g |
| Power consumption | 3.5 W |
| Ingress protection | IP67 |
| Operating temperature | -20 °C to 60 °C |
| List price | 316 EUR |

The AX-1054 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
