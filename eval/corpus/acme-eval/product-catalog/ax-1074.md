# AX-1074 Edge gateway

Product sheet for the AX-1074, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 105 g |
| Power consumption | 2.0 W |
| Ingress protection | IP67 |
| Operating temperature | -10 °C to 50 °C |
| List price | 655 EUR |

The AX-1074 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
