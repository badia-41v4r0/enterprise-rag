# AX-1053 Temperature and humidity sensor

Product sheet for the AX-1053, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 770 g |
| Power consumption | 2.0 W |
| Ingress protection | IP54 |
| Operating temperature | -20 °C to 60 °C |
| List price | 90 EUR |

The AX-1053 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
