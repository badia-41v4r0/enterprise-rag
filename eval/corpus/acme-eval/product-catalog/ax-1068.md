# AX-1068 Smart relay

Product sheet for the AX-1068, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 200 g |
| Power consumption | 5.0 W |
| Ingress protection | IP54 |
| Operating temperature | -40 °C to 85 °C |
| List price | 434 EUR |

The AX-1068 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
