# AX-1073 Temperature and humidity sensor

Product sheet for the AX-1073, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | sensor |
| Weight | 145 g |
| Power consumption | 7.5 W |
| Ingress protection | IP65 |
| Operating temperature | -40 °C to 85 °C |
| List price | 643 EUR |

The AX-1073 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
