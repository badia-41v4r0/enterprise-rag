# AX-1071 Field controller

Product sheet for the AX-1071, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 620 g |
| Power consumption | 1.5 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 104 EUR |

The AX-1071 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
