# AX-1012 Smart relay

Product sheet for the AX-1012, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 595 g |
| Power consumption | 5.0 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 96 EUR |

The AX-1012 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
