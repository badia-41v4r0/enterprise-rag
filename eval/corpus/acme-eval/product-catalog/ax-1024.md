# AX-1024 Smart relay

Product sheet for the AX-1024, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 115 g |
| Power consumption | 2.0 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 358 EUR |

The AX-1024 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
