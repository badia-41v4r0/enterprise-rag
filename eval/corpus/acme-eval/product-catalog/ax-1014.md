# AX-1014 Edge gateway

Product sheet for the AX-1014, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 665 g |
| Power consumption | 5.0 W |
| Ingress protection | IP54 |
| Operating temperature | -40 °C to 85 °C |
| List price | 386 EUR |

The AX-1014 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
