# AX-1075 Field controller

Product sheet for the AX-1075, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 470 g |
| Power consumption | 1.5 W |
| Ingress protection | IP54 |
| Operating temperature | -20 °C to 60 °C |
| List price | 263 EUR |

The AX-1075 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
