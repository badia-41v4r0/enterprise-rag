# AX-1060 Smart relay

Product sheet for the AX-1060, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 100 g |
| Power consumption | 7.5 W |
| Ingress protection | IP54 |
| Operating temperature | -30 °C to 70 °C |
| List price | 462 EUR |

The AX-1060 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
