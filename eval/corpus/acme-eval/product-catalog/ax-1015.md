# AX-1015 Field controller

Product sheet for the AX-1015, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 765 g |
| Power consumption | 3.5 W |
| Ingress protection | IP54 |
| Operating temperature | -20 °C to 60 °C |
| List price | 623 EUR |

The AX-1015 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
