# AX-1002 Edge gateway

Product sheet for the AX-1002, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 825 g |
| Power consumption | 1.5 W |
| Ingress protection | IP67 |
| Operating temperature | -10 °C to 50 °C |
| List price | 276 EUR |

The AX-1002 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
