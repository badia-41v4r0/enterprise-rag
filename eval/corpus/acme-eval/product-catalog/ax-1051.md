# AX-1051 Field controller

Product sheet for the AX-1051, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 250 g |
| Power consumption | 2.0 W |
| Ingress protection | IP67 |
| Operating temperature | -10 °C to 50 °C |
| List price | 458 EUR |

The AX-1051 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
