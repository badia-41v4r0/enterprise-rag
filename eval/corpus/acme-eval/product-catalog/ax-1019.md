# AX-1019 Field controller

Product sheet for the AX-1019, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 255 g |
| Power consumption | 1.5 W |
| Ingress protection | IP54 |
| Operating temperature | -10 °C to 50 °C |
| List price | 101 EUR |

The AX-1019 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
