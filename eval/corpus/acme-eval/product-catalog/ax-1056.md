# AX-1056 Smart relay

Product sheet for the AX-1056, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | relay |
| Weight | 850 g |
| Power consumption | 3.5 W |
| Ingress protection | IP54 |
| Operating temperature | -20 °C to 60 °C |
| List price | 68 EUR |

The AX-1056 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
