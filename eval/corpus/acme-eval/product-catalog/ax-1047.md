# AX-1047 Field controller

Product sheet for the AX-1047, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | controller |
| Weight | 575 g |
| Power consumption | 1.5 W |
| Ingress protection | IP65 |
| Operating temperature | -10 °C to 50 °C |
| List price | 171 EUR |

The AX-1047 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
