# AX-1022 Edge gateway

Product sheet for the AX-1022, part of the ACME field hardware line for ACME Cloud Planner.

| Property | Value |
|---|---|
| Family | gateway |
| Weight | 610 g |
| Power consumption | 1.5 W |
| Ingress protection | IP54 |
| Operating temperature | -30 °C to 70 °C |
| List price | 423 EUR |

The AX-1022 connects to an AX Gateway over the local radio network and is configured from the mobile app.
Warranty: two years. Firmware updates are delivered over the air.
