# ERR-460: VPN has no route to the server (AX Gateway)

**Component:** AX Gateway
**Since version:** 4.1

## Symptom

AX Gateway reports error ERR-460 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the VPN profile does not include the sync server subnet.

## Fix

To resolve it, request the updated eng-vpn profile in the IT portal. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-460
and the serial number of the device.
