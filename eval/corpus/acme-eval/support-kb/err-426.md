# ERR-426: Revoked API token (AX Gateway)

**Component:** AX Gateway
**Since version:** 4.1

## Symptom

AX Gateway reports error ERR-426 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the API token used by the integration was revoked by an administrator.

## Fix

To resolve it, create a new token in Settings > API and update the integration. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-426
and the serial number of the device.
