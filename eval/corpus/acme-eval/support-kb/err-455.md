# ERR-455: Certificado TLS caducado (API pública)

**Componente:** API pública
**Desde la versión:** 4.2

## Síntoma

El componente API pública muestra el código ERR-455 y deja de sincronizar con ACME Cloud Planner.

## Causa

En la mayoría de los casos el certificado TLS del dispositivo ha caducado y el servidor rechaza la conexión.

## Solución

Para resolverlo hay que renovar el certificado desde la consola de dispositivos y reiniciar el servicio. Si el error persiste después de 30 minutos, abrir un ticket de nivel 2
indicando el código ERR-455 y el número de serie del equipo.
