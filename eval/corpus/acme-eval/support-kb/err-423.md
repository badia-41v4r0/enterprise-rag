# ERR-423: Fallo de autenticación MFA (AX Sync)

**Componente:** AX Sync
**Desde la versión:** 4.0

## Síntoma

El componente AX Sync muestra el código ERR-423 y deja de sincronizar con ACME Cloud Planner.

## Causa

En la mayoría de los casos el segundo factor (MFA) no coincide o el código ha caducado.

## Solución

Para resolverlo hay que sincronizar la hora del móvil y volver a introducir el código. Si el error persiste después de 30 minutos, abrir un ticket de nivel 2
indicando el código ERR-423 y el número de serie del equipo.
