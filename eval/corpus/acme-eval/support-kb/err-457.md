# ERR-457: Cuota de sincronización superada (AX Sync)

**Componente:** AX Sync
**Desde la versión:** 4.0

## Síntoma

El componente AX Sync muestra el código ERR-457 y deja de sincronizar con ACME Cloud Planner.

## Causa

En la mayoría de los casos la cuenta ha superado el número de sincronizaciones por hora de su plan.

## Solución

Para resolverlo hay que esperar a la siguiente hora o ampliar el plan a Business. Si el error persiste después de 30 minutos, abrir un ticket de nivel 2
indicando el código ERR-457 y el número de serie del equipo.
