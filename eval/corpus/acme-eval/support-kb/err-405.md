# ERR-405: Fallo de autenticación MFA (Portal de clientes)

**Componente:** Portal de clientes
**Desde la versión:** 4.1

## Síntoma

El componente Portal de clientes muestra el código ERR-405 y deja de sincronizar con ACME Cloud Planner.

## Causa

En la mayoría de los casos el segundo factor (MFA) no coincide o el código ha caducado.

## Solución

Para resolverlo hay que sincronizar la hora del móvil y volver a introducir el código. Si el error persiste después de 30 minutos, abrir un ticket de nivel 2
indicando el código ERR-405 y el número de serie del equipo.
