# ERR-414: Revoked API token (AX Sync)

**Component:** AX Sync
**Since version:** 4.2

## Symptom

AX Sync reports error ERR-414 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the API token used by the integration was revoked by an administrator.

## Fix

To resolve it, create a new token in Settings > API and update the integration. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-414
and the serial number of the device.
