# ERR-438: Revoked API token (API pública)

**Component:** API pública
**Since version:** 4.1

## Symptom

API pública reports error ERR-438 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the API token used by the integration was revoked by an administrator.

## Fix

To resolve it, create a new token in Settings > API and update the integration. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-438
and the serial number of the device.
