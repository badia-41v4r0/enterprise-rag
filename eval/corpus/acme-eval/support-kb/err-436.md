# ERR-436: VPN has no route to the server (App móvil)

**Component:** App móvil
**Since version:** 4.1

## Symptom

App móvil reports error ERR-436 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the VPN profile does not include the sync server subnet.

## Fix

To resolve it, request the updated eng-vpn profile in the IT portal. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-436
and the serial number of the device.
