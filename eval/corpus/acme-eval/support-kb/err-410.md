# ERR-410: Device clock out of sync (AX Gateway)

**Component:** AX Gateway
**Since version:** 4.0

## Symptom

AX Gateway reports error ERR-410 and stops syncing with ACME Cloud Planner.

## Cause

In most cases the device clock differs by more than five minutes from the NTP server.

## Fix

To resolve it, enable NTP on the device and check UDP port 123. If the error persists after 30 minutes, open a level 2 ticket with the code ERR-410
and the serial number of the device.
