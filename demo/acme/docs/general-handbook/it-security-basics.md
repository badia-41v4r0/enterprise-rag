# IT Security Basics

Internal reference code: CANARY-GEN-7Q2F.

## Passwords and MFA

Use the company password manager. Multi-factor authentication is mandatory for email, VPN and the HR portal.
Never share one-time codes with anyone, including the IT team.

## Reporting incidents

Report phishing or a lost laptop to the security desk within one hour, via the #security-help channel or the IT portal.

## Data classification

ACME classifies information as Public, Internal or Confidential. Confidential data (HR records, salaries, finance)
must never be pasted into external AI tools.
