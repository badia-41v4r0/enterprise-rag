# ACME Corp demo

ACME Corp is a fictional company. Every document, person, number and ticket here is synthetic.

## What gets seeded

`erag seed-acme` (or the container start-up hook when `ERAG_SEED_DEMO=true`, the compose default) creates:

| Container | Classification | Canary (used by the leakage tests) |
|---|---|---|
| General Handbook | internal | `CANARY-GEN-7Q2F` |
| HR Confidential | confidential | `CANARY-HR-9XK3`; restricted case file `CANARY-HRR-5MZ8` |
| Finance | confidential | `CANARY-FIN-3TB6` |
| Engineering | internal | `CANARY-ENG-8WD1` (includes a prompt-injection document) |
| Product Docs | public | `CANARY-PUB-2LC4` |

Personas (password `acme-demo-password` unless `ERAG_DEMO_PASSWORD` is set):

| Email | Roles | Reads | Tools |
|---|---|---|---|
| `admin@acme.test` | Employee + admin flag | General, Product (admin manages, but sees data only through grants, ADR 0009) | files |
| `hr@acme.test` | Employee, HR | + HR Confidential (manage) + the restricted case file | files, search_tickets (HR) |
| `finance@acme.test` | Employee, Finance | + Finance (manage) | files, search_tickets (FIN), list_invoices |
| `engineer@acme.test` | Employee, Engineering | + Engineering (manage) | files, search_tickets (ENG) |
| `newhire@acme.test` | Employee | General, Product | files |
| `exec@acme.test` | Employee, Executive | every container, **not** the restricted case file | files, search_tickets (all), list_invoices |

MCP reference servers: `files` (this `docs/` tree, scoped by container) and `tickets` (SQLite ERP-lite with HR cases, invoices and engineering tickets, scoped by department; one ticket carries an injection attempt).

## Scenarios

Run all three against a running instance: `uv run python scripts/demo_scenarios.py --base http://127.0.0.1:8000`.

1. **Signature.** "What is the salary band for a senior engineer?" HR gets "58,000 to 72,000 EUR [1]" from *HR Confidential*, generated by the local model (classification `confidential`). The engineer only gets the career ladder and "not specified / handled by HR". The new hire gets "I don't have information about that in the sources available to you."
2. **Tool.** "Show me open invoices over 10k EUR." The finance analyst's model calls `tickets__list_invoices` and lists three invoices. The engineer's model is never offered the tool.
3. **Revocation.** The admin removes the HR role from `hr@acme.test` (Admin > Users, or the API); the same question immediately loses access. No re-index.

Try also: log in as `exec@acme.test` and ask about "HR investigation 2026-03" (container read is not enough for a restricted document), or as `engineer@acme.test` ask the model to "search tickets" (the injected ticket title is removed before the model sees it).
